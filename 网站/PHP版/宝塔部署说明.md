# PHP 版：宝塔部署（不需要 Node.js）

## 本压缩包范围

这是当前已接入版本的完整部署文件，不是所有上游游戏已完成移植的声明。首页默认简体中文，保留时之笛，并接入王国之泪、旷野之息、灾厄启示录、马力欧卡丁车7、超级卡比猎人队、卡比吸入大作战、节奏天国、宝可梦绘图方块及最终幻想探索者。各游戏已迁移范围见首页和编辑页；未接入的高级控件禁用。其余上游游戏尚未开放。未做游戏实机验证，请仅使用备份副本。

## 最简单的部署方式

1. 在宝塔 **软件商店** 安装 **PHP 8.2 或更新版本**（64 位）。不需要安装 Node.js、Composer、数据库或 ZIP 扩展。
2. 在宝塔 **网站** 中选择你的域名，设置 **PHP 版本** 为刚安装的版本。网站目录可以继续使用 `/www/wwwroot/wp.xzcqgzs.cn`。
3. 将 `OOT-SW2SE-PHP.zip` 上传到该网站目录并直接解压（ZIP 内不多套目录）；或将本 `PHP版` 文件夹**里面的全部内容**上传到该网站目录，不是只上传 `assets`，也不要多套一层 `PHP版` 目录。
4. 在网站的默认首页设置中，将 `index.php` 放在第一位；移走旧的 `index.html`，防止显示旧首页。
5. 如果以前设置过 Node 反向代理，请关闭该反向代理，使用宝塔正常的 PHP 网站配置。**本版不需要伪静态规则**。
6. 在该网站 Nginx 配置的 `server { ... }` 内加上 `client_max_body_size 24m;`，如已有此项则修改原值，不要重复添加。
7. 申请并启用 SSL，通过 `https://你的域名/` 打开即可。

上传完成后应当是：

```text
/www/wwwroot/wp.xzcqgzs.cn/
├── index.php
├── api.php
├── .user.ini               隐藏文件，建议一并上传
├── LICENSE.txt
├── 宝塔部署说明.md
├── assets/
│   ├── app.js
│   ├── api-client.js
│   └── style.css
└── private/
    ├── .htaccess
    ├── config.php
    ├── core.php
    ├── web.php
    ├── data.php
    └── cleanup.php
```

**不需要上一级的 `editor.html`，不需要运行任何启动命令。**

如果你之前把 Node 版文件上传到了网站根目录，请先备份并移走旧的 `core.cjs`、`server.cjs`、`package.json`、`test.cjs`、`public` 等文件。不要将整个 Git 仓库、`.git`、测试文件或后端 JavaScript 模块暴露在静态网站目录中。

## 确认是否部署成功

浏览器打开：

```text
https://你的域名/api.php?action=config
```

正常显示：

```json
{"service":"oot-sw2se-web","passwordRequired":false,"runtime":"php"}
```

- 如果下载了 PHP 文件或显示 PHP 源码：**立即停止公开网站**，说明 PHP 没有正确启用，后端文件有泄露风险。先在宝塔选择正确 PHP 版本再开放。
- 如果显示 HTML 首页：关闭旧的反向代理或首页回退规则，检查访问的是否是正确网站。
- 如果报 413：检查 Nginx 的 `client_max_body_size`。
- 如果报临时目录或 open_basedir 错误：见下面“临时目录”。

## 访问密码（可选）

默认没有密码，网页会显示“无需填写”。

若想限制别人使用，用宝塔文件编辑器打开 `private/config.php`，把：

```php
'password' => getenv('SITE_PASSWORD') ?: '',
```

改成你自己设置的强密码，例如：

```php
'password' => '在这里填写你自己设置的密码',
```

密码不要包含未转义的单引号或反斜杠；也可通过服务器的 `SITE_PASSWORD` 环境变量配置。实际密码不要提交到 GitHub，也不要在聊天中发送。保存后刷新网页，出现密码框，填写同一个密码即可。

这是共享访问密码，不是注册/登录系统。正式使用务必启用 HTTPS。

## 存档如何导入

先在首页选择游戏。新增游戏一次选择对应的一个存档文件，导出为该游戏的原文件名。王国之泪选择 `progress.sav`，旷野之息选择 `game_data.sav`；不要将两者混用。新增游戏单文件上限 8 MiB。

### 时之笛


- 推荐点击 **选择备份文件夹**，选择包含存档的文件夹。
- 手动选择时按住 Ctrl（Mac 为 Command），一次同时选择 `progress.sav` 和 `caption.sav`。可一起选择 `option.sav`。
- 只选择 `caption.sav` 或只选择 `progress.sav` 不能打开完整存档。
- 导出仅生成替换文件 ZIP，不是完整备份，始终在原始备份的副本上应用补丁。

## 临时目录和隐私

与 Node 版的纯内存会话不同，PHP 版使用 **PHP 文件会话**：上传存档临时保存在网站目录以外的系统临时目录中，不会作为公开文件提供下载。

- 页面通过随机令牌访问存档，不依赖浏览器 Cookie。
- 空闲 15 分钟后会话失效，后续 API 请求会顺便清理过期文件。
- 点击“清除服务器临时存档”会立即删除该会话文件。
- 不保证磁盘安全擦除，服务器管理员仍可访问数据；系统备份、交换分区及日志策略需自行管理。
- 无人访问时不会自动执行 PHP。若需要无人访问时也及时清理，添加下面的计划任务。

宝塔通常允许 PHP 访问 `/tmp`。若受 open_basedir 限制，可在 `private/config.php` 的 `storage_dir` 中指定一个**网站根目录之外**的目录，例如 `/www/oot-private/wp-saves`，创建后授权 PHP 运行用户（通常为 `www`）读写，并在站点 PHP 的 open_basedir 中允许该目录。**不要把存档目录放在可通过网址访问的位置，不要把权限改成 777。**

可选：在宝塔“计划任务”中添加每分钟运行一次的 Shell 任务。下面以 PHP 8.2 为例，根据实际安装位置调整：

```sh
/www/server/php/82/bin/php /www/wwwroot/wp.xzcqgzs.cn/private/cleanup.php
```

建议为 FPM 和计划任务明确配置相同的 `storage_dir`，避免两者系统临时目录不同。以能够访问存档目录的用户运行清理任务。

## 生产环境建议

- 关闭目录索引，禁止直接访问 `private/`。Apache 可识别自带 `.htaccess`；Nginx 可在已有 `server` 内增加：

```nginx
location ^~ /private/ {
    deny all;
}
```

即使没有这条 Nginx 规则，private 内的 PHP 文件也有直接访问保护，但仍建议配置目录拒绝访问。
- 不记录 API 请求体，不启用 PHP 错误回显。
- 确保 `.user.ini` 不作为静态文件公开（宝塔通常已有拦截）。
- API 每连接 IP 每分钟限 90 次；最多 20 个临时存档会话。代理/CDN 后所有访客可能共享连接 IP，应在代理层配置合适的限流。
- 时之笛单文件最大 2 MiB，总存档最大 12 MiB，最多 16 个文件，JSON 请求体最大 18 MiB。
- 这是单服务器初版；不支持多服务器共享会话。请先用备份副本验证，不替代真实存档的游戏内测试。
